# Data Archivist

> Exploring file handling, standard streams, error management, and safe resource handling in Python.

This module focuses on working with files and data streams in Python.  
The exercises progress from manually opening and closing files to using standard input/output streams and finally Python context managers for safe file access.

The project introduces the practical differences between reading, writing, standard input, standard output, and error output while gradually improving the reliability of file operations.

## Exercise 0 — Ancient Text Recovery

The first exercise introduces Python file objects.

A file name is passed through the command line:

```bash
python3 ex0/ft_ancient_text.py test_files/ancient_fragment.txt
```

The program:

1. validates the command-line arguments,
2. opens the requested file,
3. reads its contents,
4. displays the contents,
5. closes the file,
6. handles file access errors.

One of the important concepts introduced here is that `open()` does not return the file contents directly.

Instead, it returns a **file object**:

```python
typing.IO[str]
```

The actual text is obtained through:

```python
file.read()
```

## Exercise 1 — Archive Creation

The second exercise extends the reading system by transforming and saving archive data.

Each line of the original file receives a `#` marker:

```text
Original:

First line
Second line

Transformed:

First line#
Second line#
```

The file content is separated into individual lines using:

```python
splitlines()
```

The lines are modified and then reconstructed using:

```python
"\n".join(lines)
```

The user can then choose whether the transformed data should be saved.

```bash
python3 ex1/ft_archive_creation.py test_files/ancient_fragment.txt
```

Writing uses:

```python
open(file_name, "w")
```

The `"w"` mode:

- opens a file for writing,
- creates the file if it does not exist,
- replaces its existing contents if it already exists.

## Exercise 2 — Stream Management

This exercise introduces the three standard streams used by programs:

```text
stdin   → input
stdout  → normal output
stderr  → error output
```

### Standard Input

Instead of using `input()`, the program reads directly from:

```python
sys.stdin.readline()
```

Because `readline()` includes the newline generated by pressing Enter, the trailing newline is removed before the file name is used.

### Standard Output

Normal program output is written to:

```python
sys.stdout
```

`print()` uses `stdout` by default.

When a prompt is printed without a newline:

```python
print("Enter new file name: ", end="")
```

the stream can explicitly be flushed:

```python
sys.stdout.flush()
```

This ensures that the prompt is displayed before the program waits for input.

### Standard Error

Errors caused by exceptions are written separately to:

```python
sys.stderr
```

For example:

```text
[STDERR] Error opening file 'foo': ...
```

Separating normal output and error output allows them to be handled independently by the operating system or shell.

## Exercise 3 — Vault Security

The final exercise introduces Python's context manager system.

Earlier exercises manually managed file resources:

```text
open
 ↓
read / write
 ↓
close
```

This can become unsafe if an exception occurs before `close()` is reached.

The `with` statement solves this problem:

```python
with open(file_name, "r") as file:
    content = file.read()
```

When the `with` block ends, Python automatically closes the file.

This also happens when an exception occurs inside the block.

```text
with open(...)
      ↓
file available
      ↓
read / write
      ↓
block ends
      ↓
file automatically closed
```

The central function of this exercise is:

```python
secure_archive(
    file_name,
    action="read",
    content=""
)
```

It supports both reading and writing.

Its return type is:

```python
tuple[bool, str]
```

The boolean indicates whether the operation succeeded.

Examples:

```text
(True, "file contents")
```

```text
(False, "error message")
```

When writing succeeds:

```text
(True, "Content successfully written to file")
```

The `action` parameter defaults to `"read"`, meaning:

```python
secure_archive("archive.txt")
```

is equivalent to:

```python
secure_archive("archive.txt", "read")
```

Writing can be selected explicitly:

```python
secure_archive(
    "new_archive.txt",
    "write",
    "Archive content"
)
```

## File Handling Evolution

One of the main ideas of the module is the gradual improvement of file handling.

### Manual File Management

```text
open()
 ↓
read() / write()
 ↓
close()
```

Used in the first exercises.

### Stream-Aware File Management

```text
stdin
stdout
stderr
```

Introduced in Exercise 2 to distinguish different communication channels.

### Context Manager

```text
with open(...)
 ↓
use file
 ↓
automatic close
```

Introduced in Exercise 3 for safer resource management.
